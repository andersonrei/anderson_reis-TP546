# Checklist de entrega

- [ ] Conferir nome do aluno e disciplina no PDF.
- [ ] Conferir se o relatório tem 5–8 páginas.
- [ ] Criar o repositório no GitHub.
- [ ] Enviar o PDF.
- [ ] Enviar o diagrama.
- [ ] Enviar `REFERENCIAS.md` e `REFERENCIAS.bib`.
- [ ] Se a disciplina exigir os PDFs dos artigos, baixar os artigos diretamente das páginas dos autores/editoras e colocá-los em `referencias/artigos/`, respeitando as condições de uso.
- [ ] Copiar o link do repositório e enviar pelo portal da disciplina.
